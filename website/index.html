Un serveur MCP gratuit et open source. Claude obtient 3 outils qu'il appelle lui-même pour connaître l'heure et la météo — sans aucune extension.

🕐
get_current_datetime

Date, heure, fuseau, saison et moment de la journée.

🌤
get_weather

Température, conditions, vent et coucher de soleil (Open-Meteo).

📦
get_full_context

Le bloc d'horodatage complet, prêt à injecter.

Claude Code — une commande claude mcp add clockforclaude \ -- npx -y clockforclaude-mcp
Claude Desktop — config JSON { "mcpServers": { "clockforclaude": { "command": "npx", "args": ["-y", "clockforclaude-mcp"] } } }

Nécessite Node.js ≥ 18 · 100 % gratuit · github.com/clockforclaude

FAQ

Questions fréquentes

Mes données sont-elles privées ?

Oui, totalement. Vos réglages et votre position sont stockés localement dans votre navigateur. Aucune donnée n'est revendue. Seules vos coordonnées (latitude/longitude) sont envoyées à l'API météo gratuite Open-Meteo, sans aucune information personnelle.

Comment fonctionne l'abonnement Pro ?

Le Pro coûte 2,49 €/mois via Stripe. Après paiement, vous recevez une clé de licence au format CFC-XXXX-XXXX-XXXX à coller dans les réglages de l'extension pour débloquer l'injection automatique, la météo dynamique et le calendrier. Annulable à tout moment depuis votre espace Stripe.

Sur quels appareils ça marche ?

L'extension fonctionne sur Chrome, Brave, Edge et Firefox. La WebApp copier-coller fonctionne partout (iPhone, Android, PC). Le connecteur MCP s'utilise dans Claude Desktop et Claude Code. Safari et les apps natives iOS/Android arrivent bientôt.

Le connecteur MCP est-il payant ?

Non, le serveur MCP est 100 % gratuit et open source. Installez-le en une commande avec npx clockforclaude-mcp (Node.js ≥ 18 requis).

ClockForClaude est-il affilié à Anthropic ?

Non. ClockForClaude est un projet indépendant, non affilié à Anthropic. « Claude » est une marque d'Anthropic ; ce produit l'utilise uniquement pour décrire la compatibilité.
