# ClockForClaude — Code Source de l'Application Mobile / Mobile App Source Code

Ce dossier contient le code source de l'application mobile **ClockForClaude** (développée avec React Native et Expo). Cette application est un conteneur natif (WebView) sécurisé pour `claude.ai` avec injection automatique de l'heure locale, de la météo et du calendrier de l'appareil.

L'application est destinée à être compilée et publiée directement sur l'Apple App Store et le Google Play Store. Elle ne nécessite donc aucune notice d'installation ou de configuration manuelle pour les utilisateurs finaux.

---

This folder contains the source code for the **ClockForClaude** mobile application (built with React Native and Expo). This app is a secure native container (WebView) for `claude.ai` with automatic local time, weather, and device calendar context injection.

The application is designed to be compiled and published directly to the Apple App Store and Google Play Store. Therefore, it does not require any manual setup or installation instructions for end-users.
