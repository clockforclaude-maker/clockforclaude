# 🕒 ClockForClaude — Google Chrome Extension (Desktop)

This folder contains the **Google Chrome Extension** for ClockForClaude. It injects real-time context (current date, time, and local weather) directly into your Claude.ai prompts.

---

## 🇫🇷 Français

### 🌟 Fonctionnalités Clés
* **Injection Temporelle en Temps Réel :** Insère la date, l'heure exacte et la météo locale avant vos prompts.
* **Prompts Rapides Personnalisés :** Accédez à vos modèles de prompts (jusqu'à 5 avec l'Option Pro) pour les injecter instantanément depuis des boutons cliquables.
* **Mode Sombre Claude :** Force l'application du thème sombre sur l'interface de Claude.ai.

### ⚡ Comparatif Version Gratuite vs PRO
* **Version Gratuite (FREE) :**
  * Insertion manuelle du contexte (date, heure, météo) en cliquant sur le bouton **🕒 Clock**.
* **Version PRO (Abonnement) :**
  * **Injection Automatique :** Le contexte s'insère automatiquement à chaque message ou au premier message du chat selon vos préférences, sans aucun clic.
  * **Boutons Personnalisés :** Créez et sauvegardez jusqu'à 5 modèles de prompts rapides personnalisés.
  * **Mises à jour automatiques** de la météo en arrière-plan.

### 💻 Installation
Installez l'extension directement depuis le [Chrome Web Store (Lien à venir)](#).

## 🇺🇸 English

### 🌟 Key Features
* **Real-Time Context Injection:** Prepend exact time, date, and local weather before your prompts.
* **Custom Quick Prompts:** Save up to 5 custom prompt templates (Pro feature) to inject them instantly from clickable buttons.
* **Claude Dark Mode:** Easily enable dark mode styling on the Claude.ai web interface.

### ⚡ Free vs PRO Plan
* **Free Version:**
  * Manual context insertion (date, time, weather) by clicking the **🕒 Clock** button.
* **PRO Version:**
  * **Automatic Injection:** The context is prepended automatically on every prompt (or just the first message of a chat) without clicking anything.
  * **Custom Prompt Buttons:** Create, edit, and save up to 5 custom prompt templates.
  * **Automatic Updates:** Background updates for local weather.

Install the extension directly from the [Chrome Web Store (Link Coming Soon)](#).
