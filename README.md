# 🕒 ClockForClaude — Desktop Extension & Mobile App

Welcome to **ClockForClaude**! The ultimate tool to inject real-time context (current date, time, local weather, and custom prompt templates) directly into the Claude.ai conversation prompt box.

<summary><b>🇺🇸 English (American)</b></summary>

### 🌟 Key Features
* **Real-Time Context Injection:** Prepend exact time, date, and local weather before your prompts.
* **Custom Quick Prompts:** Save up to 5 custom prompt templates (Pro feature) to inject them instantly from clickable buttons.
* **Claude Dark Mode:** Easily enable dark mode styling on the Claude.ai web interface.

### ⚡ Free vs PRO Plan
* **Free Version:**
  * Manual context insertion (date, time, weather) by clicking the **🕒 Clock** button.
  * Access to base layout features.
* **PRO Version:**
  * **Automatic Injection:** The context is prepended automatically on every prompt (or just the first message of a chat, depending on your settings) without clicking anything.
  * **Custom Prompt Buttons:** Create, edit, and save up to 5 custom prompt templates for instant injection.
  * **Automatic Updates:** Background updates for local weather.

### 💻 Chrome Extension Installation
Install the extension directly from the [Chrome Web Store (Link Coming Soon)](#).

### 📱 Mobile App Installation
Download the official mobile app directly from the [Apple App Store](#) and [Google Play Store](#).

### 💡 How to Use
1. Open [claude.ai](https://claude.ai) on your browser or open the Mobile App.
2. Click the **🕒 Clock** button to manually insert the current timestamp & weather into your message box.
3. If you have **Pro**, the context can be injected automatically on every new prompt.
4. Click on any of your **Custom Prompts** buttons to instantly insert a saved template.
